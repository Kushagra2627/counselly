# Counselly Web Client

This is the React 19 + TypeScript + Vite frontend application for **Counselly** ("Fractional General Counsel for Startups"), integrated with the **InsForge** cloud backend.

> For comprehensive system architecture, database schema, and live deployment details, please see the root [README.md](../README.md).

## Live URL
- **Production Site:** [https://a2a2t997.insforge.site](https://a2a2t997.insforge.site)

## Tech Stack
- **Framework:** React 19 + Vite 8
- **Language:** TypeScript 5.6
- **Routing:** React Router DOM 7
- **Backend SDK:** `@insforge/sdk`
- **Styling:** Custom CSS Design System (variables, typography, utilities, and components)

## Local Development
```bash
# Install dependencies
npm install

# Start Vite dev server on http://localhost:3000
npm run dev

# Compile TypeScript and build for production
npm run build
```
